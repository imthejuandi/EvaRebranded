# Official EVA wordmark — 03.27

The shared EvaWordmark component uses the supplied official artwork in the landing header and footer, system header, and history header. It replaces the typed, negatively tracked approximation.

Source: /art/eva-official-logo.png (1825 × 676 pixels, 73,756 bytes).
SHA-256: 682fac5978cbae0973318e139fcb6dda60925f30e762ea190cce27fe7ad9977f
The project asset matches the supplied file byte for byte.

The transparent artwork is a CSS mask using currentColor. Geometry, spacing and the registered mark stay intact; the existing cream and dark header colors remain legible. It is 100px wide on desktop, 78px at widths up to 700px, always at the original aspect ratio. The home link has an accessible name and a minimum 44px height. No JavaScript or animation is added.

Visual review: mobile at 390px and 320px; desktop at 1440px. The narrow phone header fits without overlap or horizontal overflow, including with the menu open. The prior 03.26 source is preserved in Git and /archive/eva-03-26-narrow-menu.zip.
