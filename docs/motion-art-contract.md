# EVA motion and art contract

12 September 2026. Dedicated art-direction pass for the interactive public-site and webapp preview. This is an implementation brief, not a generation claim. No Site source was changed and no new image/video job was submitted.

## The visual principle

Keep the contrast that makes the accepted design specific: a believable person or ordinary action, rendered in tactile light, beside precise information that stays readable. The glow belongs to the photograph. The dots belong to how EVA reveals, organizes and compares information. A beautiful effect must have a job.

The fixed foundation remains ink `#0b1010`, warm paper `#f3f0e8`, paper text `#171b18`, amber `#e9a067`, muted sage `#b9bdae`. Coral, violet and blue live within image light and selected glass instruments; do not turn whole working pages lilac. Actual logo artwork stays sharp in its native proportions. Do not regenerate its lettering.

Images should contain selective detail: a hand, fabric seam or facial outline readable inside a broad optical bloom, with saturated edges and fine grain. Avoid simply adding an even CSS blur to a normal stock photograph. The glow must follow light and contours, with dark areas retaining density. Skin remains natural. The rejected halftone-person experiment is not a new direction.

## Reusable Remotion approach

Create two new pure visual compositions first: `SampleJourneyFilm` and `DocumentTranslationFilm`. An optional `ReadingBandFilm` can follow if the dashboard needs motion after static review. Keep one lightweight host shared across pages; do not embed a separate player per card.

- Composition inputs: locale, width, height, reducedMotion/static mode, content labels, progress/frame. No domain fetches inside art. Root's sample adapter supplies states; images and shape geometry are separate presentation data.
- Preserve installed Remotion 4.0.522. Existing `AbsoluteFill`, `useCurrentFrame`, `useVideoConfig`, `interpolate` and `PlayerRef.seekTo` are enough. Deterministic interpolation only; no Date.now, random particles regenerated every frame or CSS animation that drifts from the composition.
-30 fps compositions; short2.8–3.8 s timelines. Headline and captions remain semantic HTML siblings, with SVG/canvas aria-hidden. This makes text readable without waiting for the animation bundle and supports selection/screen readers.
- Lazy-load the player only when its section approaches the viewport. Initially render a complete SVG/static poster at its reserved aspect ratio. No layout jump duringload. One observer+visibility handler stops work when outside the viewport or document hidden.
- Prefer DOM/SVG for dozens of marks. If a field needs hundreds, one bounded canvas is cheaper than many independently animated DOM nodes. Cap device pixel ratio at1.5for decorative canvas; prefer ≤320 dots desktop / ≤160 mobile for new finite scenes. These are implementation budgets, not measured performance claims.
- Scroll-linked motion must map native section progress directly to a frame using a passive scroll listener and one scheduled requestAnimationFrame. Do not integrate velocity or add inertial scroll that causes lag. Avoid seeking unrelated videos every frame. The actual landing already uses thisdirect mapping pattern.
- A returning visitor should not have to rewatch a demonstration to read. Once played, leave the final frame visible until explicit Replay; respecting reduced motion meanscomplete composition with no motion, not missing art.
- Never apply changing CSS blur/backdrop-filter to a full-viewport moving image. Bake glow/grain into media; animate opacity/translation only. Use existing offscreen video pause principles for any future clip.
- Images: write responsive 600/1000/1600 px variants with a focal point, dimensions, meaningful alt text or decorative empty alt. Start with AVIF/WebP if available, static poster first. Only the landing hero remains eagerly loaded; inner-page secondary media lazy loads.
- Suggested budgets: ≤150 KB mobile hero image /≤250 KB desktop hero image; ≤1 principal animated scene per inner page; no additional continuous loops behind form/table content; no blocked interaction while media loads. Measure actual payload and revise if exceeded rather than claiming these targets achieved.

## Finite review loop and handoff

For each page, inspect 3 states: first paint, animated midpoint, resting/selected state. Repeat at 1440×900 and 390×844, then reduced motion. Check reverse scroll for scroll scenes, explicit Replay, viewport leave/reentry and document hidden. Functional data/CTA text must be readable at all frames. Labels never cover head/hand/action in lifestyle images.

Pass 1 identifies actual failures: overlap,wrong meaning, medical claim, duplicated art, unstable geometry, unreadable labels, animation running offscreen, unexpected jump. Return concrete corrections to the owning page agent. Pass 2 verifies only those corrections and connected route behavior. Stop when the list is closed. Do not use indefinite aesthetic scores or recurring regeneration.

Deliver each artwork with source/brief/model/job when generated, selected file, responsive variants, focal point, alt text, allocation (route), poster/static mode and archive previous revision. Rejected media remain archived, never accidentally surfaced because a filename looks relevant. In particular, the older Tasso walk placement and logo-vibrating pouch videos are excluded.
